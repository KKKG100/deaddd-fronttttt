# DEAD FRONT — Multiplayer

A persistent, shared-world zombie-defense RTS. One authoritative Node server simulates a huge map
(560×400 tiles, ~10× the old Endless map) and any number of browsers connect as players.

* Every player gets their own base on a free stretch of land.
* If your Command Center falls you can **redeploy in a new location** and start over.
* **Alliances** (propose/accept, break any time): shared minimap vision, build inside each other's supply range,
  allied medics/hospitals heal you, allied engineers repair you.
* **Aid**: send credits, materials and fuel to anyone (Players panel, key `P`).
* Chat (`Enter`, `/a …` for allies only). Nests are indestructible and evolve; difficulty is scaled per area by how long
  nearby players have been alive, so late joiners are not crushed by veteran-level hordes. Nests only activate when a player is within ~110 tiles.

## Deploy on Render (GitHub)

1. Create a new GitHub repo and push this folder (`git init && git add . && git commit -m init && git push`).
2. On Render: **New → Blueprint** (uses `render.yaml`) or **New → Web Service**, pick the repo, then:
   * Build command: `npm install && npm run build`
   * Start command: `npm start`
   * Environment: Node 18+
3. Open the `https://<your-service>.onrender.com` URL. Share it with friends — that's the game.

Notes
* **Use at least the Starter plan** for real play. The free plan has a very small CPU share and sleeps after ~15 idle minutes
  (the world is wiped whenever the service restarts or wakes from a cold start).
* The world lives in memory. A restart generates a fresh map. The world pauses while nobody is connected.
* Optional env vars: `MAX_PLAYERS` (24), `MAX_ZOMBIES` (1500), `SEED` (fixed map seed), `PORT`.
* The browser connects to the same host it was loaded from (`wss://` automatically on https).

## Run locally

```
npm install
npm run build     # bundles src/ -> server/sim.js and public/index.html
npm start         # http://localhost:3000
```
`DEBUG=1 npm start` enables a few testing commands.

## Layout
* `src/` — game source (shared rules/world, server sim, client renderer/UI/net)
* `server/index.js` — HTTP + WebSocket server, snapshots, commands
* `server/sim.js`, `public/index.html` — generated by `build.sh`
